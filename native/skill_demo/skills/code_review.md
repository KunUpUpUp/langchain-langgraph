# 代码审查技能

## 触发条件
当用户要求审查代码、review 代码、检查代码质量时，使用此技能。

## 执行流程

### 第1步：读取代码
- 读取用户指定的文件内容
- 如果文件不存在，告知用户并终止

### 第2步：代码统计
- 统计总行数、代码行、注释行、空白行
- 如果注释行占比低于 10%，提醒注释不足

### 第3步：风格检查
- 检查是否有超过 120 字符的行
- 检查是否使用了 tab 缩进（应使用空格）
- 检查行尾是否有多余空格
- 检查命名是否符合 PEP8（函数用 snake_case，类用 PascalCase）

### 第4步：安全检查
- 检查是否使用了 eval()、exec()
- 检查是否使用了 os.system()（建议用 subprocess）
- 检查是否有硬编码的密码、密钥、token

### 第5步：生成报告
按以下格式输出审查报告：

```
========== 代码审查报告 ==========
文件: xxx

【代码统计】
  总行数 / 代码行 / 注释行 / 空白行

【风格问题】
  - 问题列表

【安全问题】
  - 问题列表

【结论】
  总结 + 改进建议
====================================
```

## 注意事项
- 每个步骤都要执行，不能跳过
- 即使没有问题也要在报告中说明"无问题"
- 安全问题优先级最高，必须重点标注
